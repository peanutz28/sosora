# Repository scope and local resources

This branch contains Ria-owned ML source, tests, pinned dependency lists, source/reproducibility manifests, numerical evidence and documentation. It does not modify teammate frontend/backend, shared contracts, demo data or the root README.

## Deliberate exclusions

- `.env` and local secrets; account/credit details; auth/session storage.
- Virtual environments, downloaded CLI binaries, caches and Python bytecode.
- Downloaded imagery/labels, model weights/checkpoints and temporary run artifacts.
- Generated viewer photos, masks, overlays, prediction GeoJSON/JSON, screenshots and data bundles. Small size does not resolve source licensing; regenerate privately from approved local inputs.

The local interactive console remains at port 9030; excluding its generated assets does not remove them from the current machine. Its authored HTML/CSS/JavaScript and preparation/server code are included. The saved training page is generated by `scripts/ml/build_training_viewer.py`; it is not the interactive homepage.

## Reproduction boundaries

Install the pinned vision environment using Python 3.12. Dataset URLs, public source records, split methodology, model revision, checkpoint hashes and numerical results are in `data/manifests/` and `docs/ml/evidence/`.

Preparation/training tools include `prepare_sn8_pilot.py`, `prepare_road_crops.py`, `train.py`, `prepare_road_demo.py`, `prepare_helene_roads.py`, `prepare_noaa_helene_demo.py`, and the frozen external preparation/evaluator. They write local artifacts and refuse destructive overwrites. Where a tracked manifest already exists, use a new manifest-output path where supported or preserve the supplied manifest and prepare its referenced local data; do not delete evidence to rerun.

The selected training settings and complete experimental protocol are in the numerical evidence. The trained checkpoint is not shipped: its upstream model-license metadata needs review before redistribution. The source tree cannot serve real inference on a fresh machine until weights/data are recreated or supplied privately. Current-machine launch commands are in `TEAMMATE_INTEGRATION.md`; `CONSOLE.md` documents local asset generation and the fixed loopback API proxy.

NOAA October 2024 response imagery is distinct from NC spring 2025 recovery imagery and SpaceNet 8 training/evaluation. Source processing/analysis restrictions and attribution requirements remain in `PITCH_PROVENANCE.md`. Numerical evidence is not image redistribution or a claim that Helene predictions are correct.

NeMo Gym has a separate pinned core runtime/bootstrap and synthetic CC0 scenarios; see `NEMO_GYM.md`. Its protocol tests do not establish a real language-model score. No provider credentials or full upstream CLI harness are bundled.
